# موقع الطوارئ لمؤسسة جودي الكوفة العلمية

حزمة ثابتة مؤقتة ومستقلة عن Blogger، مبنية لتبقى هوية المؤسسة وروابط التواصل الرسمية متاحة أثناء معالجة الموقع الأصلي.

## المسارات

- `/` الصفحة الرئيسية الرسمية برسالة تحديث تقنية محايدة.
- `/links` دليل قنوات التواصل الرسمية، وهو الرابط الدائم للـQR. يخدمه Vercel بإعادة كتابة داخلية، بينما يضيف GitHub Pages الشرطة النهائية ويعرض الصفحة الفعلية في `/links/`.
- `/links.html` و`/p/links.html` و`/p/links` تنتقل إلى `/links/` على GitHub Pages للمحافظة على الروابط القديمة؛ يستخدم Vercel تحويلاته المؤقتة الخاصة.
- أي رابط غير متاح يعرض `404.html` بهوية المؤسسة وخيارات رجوع آمنة.

## التحقق المحلي

يتطلب Node.js فقط:

```powershell
npm.cmd test
```

## النشر والتراجع

نشر الطوارئ المجاني يعمل على GitHub Pages من المستودع العام المعزول `jaafer-0/judyalkufa-emergency-site`. الملف `.nojekyll` يمنع معالجة Jekyll، وتوفر الملفات داخل `links/` و`p/` المسارات الفعلية التي يحتاجها الرابط الدائم والـQR.

تبقى معاينة Vercel متاحة؛ عند استخدامها يُضبط مجلد المشروع على `emergency-site` ويحفظ `vercel.json` التحويلات والترويسات الخاصة بها.

لا تتطلب العودة إلى Blogger أي تغيير في هذه الملفات: بعد استعادة المدونة والتحقق منها، تُعاد سجلات DNS السابقة الموثقة في تذكرة التحويل، ويبقى نشر الطوارئ متاحًا إلى أن يثبت نجاح العودة.
